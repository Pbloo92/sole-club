# SOLE//CLUB

Proyecto sencillo de React + Vite + Tailwind CSS para una tienda conceptual de zapatillas urbanas.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Instalar

```bash
npm install
```

## Ejecutar en local

```bash
npm run dev
```

## Preparar para producción

```bash
npm run build
```

La web incluye navegación, menú móvil, filtros por categoría y contador de carrito de demostración. No procesa pagos ni guarda el carrito al recargar.
